# chimera

Пассивный сенсор сети и хоста из частей на разных языках: ядро захвата на C, агенты на Bash и PowerShell, анализ на Go, хранилище на SQL. Всё сводится в одну базу, где сетевые события сопоставляются с хостовыми.

Статус: начато, только ядро на C. Мониторьте только сети и хосты, которыми вы владеете или на наблюдение за которыми у вас есть разрешение.
