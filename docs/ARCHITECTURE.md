# Архитектура

```
 сеть ─▶ ядро (C) ──┐
                    ├─▶ SQLite ─▶ анализ (Go) ─▶ HTTP / отчёты
 хост ─▶ агенты ────┘
        (Bash, PowerShell)
```

| часть | язык | статус | задача |
| :-- | :-- | :-- | :-- |
| ядро | C | сделано (чтение pcap) | разбор пакетов, DNS, SNI, запись событий |
| хранилище | SQL | сделано (схема v1) | потоки, DNS, TLS; индексы и представления для анализа |
| агенты Linux | Bash | в планах | автозапуск, сетевые соединения, процессы |
| агенты Windows | PowerShell | в планах | автозапуск, соединения, реестр; запускать в этой среде нельзя, только писать |
| анализ | Go | сделано | аномалии DNS и TLS, маяки, сопоставление с хостовыми событиями, HTTP |
| ассемблер | x86-64 | в планах | небольшой безобидный модуль (счётчик тактов) для ядра |
| живой захват | C + libpcap | в планах | то же ядро, но с интерфейса, не из файла |

## Принципы

- Только пассивное наблюдение: ничего не отправляется в сеть, ничего не исполняется.
- Всё, что читает недоверенные данные (pcap, ответы агентов), проверяет границы и ограничивает размеры.
- Каждая часть публично говорит, что она проверяла и что нет.
